# 电子斗蛐蛐 · 两个人一部手机当场决斗

手机平放桌上,屏幕上下分半(上半边界面倒转 180°给对面的人),五局三胜:

- **抢绿灯**:红灯憋住,绿灯抢拍——抢跑当场判负,战报点名羞辱
- **连点大战**:3 秒内看谁把屏幕点冒烟
- **放手快**:两人都按住不动,「放!」字一出先松手者胜,松早了判负
- 每局随机抽取,反应毫秒数实时记录
- 战报:比分 + 逐局记录 + 全场最快反应,胜者「本桌蛐蛐王」,败者「奶茶买单侠」
- 可以给双方起名号,战报直接点名
- 单文件 39KB,零依赖,无联网对战服务器——因为对手就坐你对面

适用场景:饭桌、办公室、情侣吵架判定、谁去拿外卖。

`src/` 下模板,`node build.js` 重新构建。
